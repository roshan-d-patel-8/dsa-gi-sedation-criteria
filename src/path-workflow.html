MD-MA QuickAction protocol for procedure path results

COLONOSCOPY PATH
For MD:

Create a QuickAction with standard message and recommendation for surveillance interval. Auto populated to route to MA inbox.

  1. New QuickAction -> Result management
  2. Name QuickAction (ex: CRC 3 years, CRC 5 years, etc)
  3. Route to: type in local MA/ MA inbox
  4. Type in message: “Colon polyp path benign. Repeat colonoscopy advised in X(smartlist) years.”
QuickAction options:
  • Separate QuickAction’s for all surv intervals (3, 5, 7, 10, no further screening, resume average risk screening)- 2 clicks
  • One QuickAction with Smartlist containing drop down menu for surveillance options- 3 clicks
For MA’s:

MA sends email or letter to patient using standard dotphrase (ex: MACOLONDSA) and sends to patient on MD’s behalf.

EGD PATH
For MD

Create a QuickAction with standard message, auto-populated to route to MA inbox.

  1. New QuickAction -> Result management
  2. Name QuickAction
  3. Route to: type in local MA/ MA inbox
  4. Type in message: “Please send normal EGD letter.”
For MA

MA sends email or letter to patient using standard dotphrase (ex: MAEGDDSA) and sends to patient on MD’s behalf.

EGD/ COLONOSCOPY (TURN) PATH
For MD’s

Create a QuickAction with standard message, auto-populated to route to MA inbox.

  1. New QuickAction -> Result management
  2. Name QuickAction
  3. Route to: type in local MA/ MA inbox
  4. Type in message: “Please send normal EGD and colonoscopy (TURN) letter. Repeat colonoscopy advised in X(smartlist) years.”
For MA’s:

MA sends email or letter to patient using standard dotphrase (ex: MAEGDDSA) and sends to patient on MD’s behalf.

Advantages:
  • MD message and recommendation attaches as a result note to path result, documenting MD recommendation in HC for everyone.
  • Uses less time and minimal clicks as no need to generate email or encounter.
  • Reduces MD inbox message replies to normal/ benign path result emails. Adds up over tenure.

Note: MD still has to update PROMPT with surveillance interval.
